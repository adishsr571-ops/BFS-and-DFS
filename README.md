File System Representation and Search Using BFS and DFS

Overview

This project implements a graph-based file system representation using the C programming language. It uses an adjacency matrix to represent connections between files and directories.

Features

- Graph representation using an adjacency matrix.
- Breadth-First Search (BFS) traversal.
- Depth-First Search (DFS) traversal.
- Search for a specified file.
- Sample input and output.

Technologies Used

- C Programming Language
- Data Structures and Algorithms

Learning Outcomes

This project helps understand graph traversal, queues, recursion, and searching techniques using BFS and DFS.

Conclusion

The project demonstrates how graph algorithms can be used to represent and search a simplified file system.
